# JASMINE Toolkit

The `jasmine_toolkit` package is a Python library designed to evaluate the performance of astronomical space telescopes, with a particular focus on the [JASMINE][jasmine] project. JASMINE (Japan Astrometry Satellite Mission for INfrared Exploration) is a space telescope project aimed at conducting precise astrometric and photometric measurements in the infrared spectrum. This toolkit provides specialized modules and utilities to assist researchers and engineers in analyzing and simulating the performance of the JASMINE telescope.

[jasmine]: https://jasmine.nao.ac.jp/index-en.html

## Installation

To install the `jasmine_toolkit` package, use the following command:

```bash
pip install git+https://github.com/JASMINE-Mission/jasmine_toolkit.git
```

This command fetches the package source code from the specified GitHub repository and installs it in your Python environment. Make sure you have `git` installed on your system and that your Python environment is properly set up before running the command.
